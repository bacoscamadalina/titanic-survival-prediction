# Titanic Survival Prediction

A compact machine learning project that predicts passenger survival from the Titanic passenger dataset. The notebook follows a simple workflow: load and inspect the data, examine survival patterns by sex, prepare selected features, train a Random Forest classifier, and generate a Kaggle-compatible submission file.

## Project Overview

The goal is to predict the binary `Survived` outcome for passengers in `test.csv`. The project uses passenger class and family-related information together with sex as model inputs.

The current implementation is intentionally straightforward and provides a reproducible baseline for future experimentation.

## Repository Contents

```text
.
├── titanic_prediction.ipynb  # Analysis, preprocessing, training, and prediction
├── train.csv                 # Labeled training data
├── test.csv                  # Unlabeled test data
├── gender_submission.csv     # Example submission supplied with the dataset
└── submission.csv            # Predictions generated by the notebook
```

## Implemented Workflow

### Exploratory Data Analysis

The notebook:

- previews the training and test datasets;
- calculates survival rates separately for female and male passengers;
- observes survival rates of approximately **74.2% for women** and **18.9% for men** in the training data.

No additional charts, correlation analysis, missing-value analysis, or outlier analysis are currently implemented.

### Preprocessing and Features

The model uses the following features:

- `Pclass` — passenger ticket class;
- `Sex` — passenger sex;
- `SibSp` — number of siblings or spouses aboard;
- `Parch` — number of parents or children aboard.

`pandas.get_dummies()` converts the categorical `Sex` feature into numeric indicator columns. The same selected columns are prepared independently for the training and test datasets. The current feature set contains no missing values, so the notebook does not apply imputation.

### Model

The notebook trains one `RandomForestClassifier` from scikit-learn with:

```python
RandomForestClassifier(
    n_estimators=100,
    max_depth=5,
    random_state=1
)
```

The fitted model predicts survival for all rows in `test.csv` and saves the results to `submission.csv` with the required columns:

- `PassengerId`
- `Survived`

## Evaluation Status

The current notebook does **not** create a validation split, perform cross-validation, or calculate evaluation metrics such as accuracy, precision, recall, F1 score, or ROC AUC. Therefore, no local performance score is reported in this README.

`submission.csv` contains predictions for the test set, whose labels are not included in the project. Model performance can be measured by submitting this file to the Titanic competition or by adding a local validation workflow.

## Setup and Usage

### 1. Create and activate a virtual environment

```bash
python -m venv .venv
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 2. Install the dependencies

```bash
python -m pip install numpy pandas scikit-learn jupyter
```

### 3. Run the notebook

Keep `train.csv` and `test.csv` in the same directory as the notebook, then start Jupyter:

```bash
jupyter notebook titanic_prediction.ipynb
```

Run all cells in order. The final modeling cell creates or replaces `submission.csv`.
